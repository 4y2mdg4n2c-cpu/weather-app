# Weather App 🌦

Простой консольный проект на Python для получения актуальной погоды через OpenWeather API.

---

## 🚀 Возможности

- Поиск погоды по названию города
- Отображение:
  - температуры
  - ощущаемой температуры
  - влажности
  - скорости ветра
  - страны
- Поддержка русского языка
- Обработка ошибок:
  - неверный город
  - таймаут запроса
  - проблемы с сетью
- Использование `.env` для защиты API ключа

---

## 🛠 Технологии

- Python 3
- requests
- python-dotenv
- OpenWeather API

---

## 🔐 Безопасность

API ключ хранится в `.env` и не загружается в GitHub.

---
